# 🔍 Why Go?

Go caught my attention because it sits at an interesting intersection:

```text
        Simplicity
            │
            ▼
        ┌───────┐
        │  Go   │
        └───────┘
       ↙    ↓    ↘
Performance  APIs  Concurrency
      ↓       ↓       ↓
   Systems  Backend  Services
```

Go's simplicity, strong tooling, fast compilation, built-in concurrency primitives, and suitability for backend/networked software make it a language worth understanding deeply.
